# Beginner Excel Interactive Sales Dashboard

## Project overview
An internship-ready beginner Excel portfolio project built from a small e-commerce dataset. It combines order, customer, product, category, and order-item data into an analysis table and an interactive dashboard.

## Dashboard features
- KPI cards: Total Revenue, Orders, Units Sold, Customers
- Dropdown filters for Order Status and Country
- Revenue by Category bar chart
- Monthly Revenue Trend line chart
- Clean source-data sheets formatted as Excel tables
- Analysis sheet with calculated line-item revenue (`quantity × unit_price`)

## How to use
1. Download and open `Beginner_Interactive_Sales_Dashboard.xlsx` in Microsoft Excel (desktop recommended).
2. Go to the **Dashboard** sheet.
3. Change the yellow dropdown cells for **Order Status** and **Country**. KPI cards and charts recalculate based on the selections.
4. Browse the source sheets and the `Analysis` sheet to understand the data model.

## Dataset sheets
- `Orders`
- `Order_Items`
- `Customers`
- `Products`
- `Categories`
- `Analysis`

## Skills demonstrated
Excel tables, data cleaning/merging, SUMPRODUCT, COUNTIFS, dropdown Data Validation, KPI design, bar charts, line charts, number/date formatting, and dashboard layout.

## Important note
The workbook uses formulas and dropdown filters rather than native PivotTable slicers, keeping the project beginner-friendly and easy to inspect. Excel recalculates formulas when the workbook opens.
